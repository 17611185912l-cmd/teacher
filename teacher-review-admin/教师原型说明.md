# 教师入驻与管理原型说明

## 原型范围

当前合并原型包含一个小程序端入口和三个管理端入口：

| 分类 | 页面 | 目标用户 | 核心目标 |
| --- | --- | --- | --- |
| 小程序 | 问答入驻 | 申请入驻的老师 | 通过小U对话、资料识别和提交前确认完成入驻 |
| 管理端 | 教师入驻管理 | 产品、运营管理人员 | 配置问答流程、字段来源、识别映射和发布版本 |
| 管理端 | 教师管理 | 审核、教务和运营人员 | 查询、查看、审核、编辑和运营教师资料 |
| 管理端 | 教师内容管理 | 内容运营人员 | 维护全局共用的教师类型、教师标签、个人简介、教学侧重和教学成果 |

## 核心流程

1. 老师进入“问答入驻”后先查看欢迎页，并选择“上传简历”或“问答填写”；两个入口只决定首次进入方式，并共用同一套问答、会话进度、资料确认和提交流程。
2. 系统仅用识别结果补齐空白字段，不覆盖老师已确认内容。
3. 入驻开始时随机带入 1 条已启用的个人简介模板，随机预选 3 个教学侧重标签，老师可修改。
4. 老师在资料确认页保存或提交申请；提交后回到个人中心等待审核。
5. 最新提交的申请同步到“教师管理”，初始审核状态为“待审核”。
6. 管理人员点击教师姓名查看只读详情；点击“编辑”后才可修改字段。
7. “教师内容管理”的个人简介与教学侧重会影响后续入驻和教师编辑；教师标签会影响管理端教师编辑的可选项；教学成果仅维护用户端展示案例，不进入入驻或教师资料。

## 页面说明

### 问答入驻

- 进入对话前展示欢迎页，说明入驻目标、预计耗时、填写方式、修改机制与资料用途。
- 欢迎页提供“上传简历”和“问答填写”两个入口；上传简历为主入口，问答填写为次入口。
- 选择问答填写后，从第一个未完成的必填问题进入对话；选择上传简历后，先在欢迎页完成解析，再进入同一问答流程。
- 会话开始后记录当前聊天内容和问答进度；再次返回欢迎页时，无论选择上传简历还是问答填写，都直接续接原会话的当前阶段，不重新开始或重复解析。
- 简历已识别的字段不重复询问；系统从第一个缺失必填字段继续。必填资料已完整时直接提供资料确认入口。
- 简历解析失败时停留在欢迎页，支持重新上传或切换到问答填写，不创建半完成的问答会话。
- 基础资料完成后即可提交；简历、证件、形象照、个人简介和教学侧重可后续补充。
- 个人简介使用内容模板预填，教学侧重在入驻中保持简洁的标签选择形态。
- 教龄为必填数字输入，填写具体年数；简历可识别并带入，老师可在资料确认页修正。
- 当前不包含教学成果字段或教学成果模板。

### 教师入驻管理

- 页面包含“问题流程、欢迎语配置、字段与识别、发布记录”四个页签，顶部“发布配置”将当前草稿生成新的正式版本。
- “问题流程”展示序号、问题 ID、问题文案、关联字段、跳过设置、状态和操作。问题支持新增、编辑、删除及列表启停。
- 新增或编辑问题时维护问题 ID、问题名称、提问文案、跳过设置、答案写入字段和启用状态；提问文案最多 160 字。
- 答案写入字段可直接选择一个或多个字段，选择数量隐式表达单字段或组合字段，不再单独配置写入方式。字段类型、来源、填写规则、系统字典和校验规则统一继承字段配置。
- “欢迎语配置”仅维护老师进入小U对话后首先展示的欢迎语，必填且最多 160 字。
- “字段与识别”维护资料识别映射、年级科目联动和字段配置清单。
- 字段清单包含字段 ID、字段名称、数据类型、多个来源、必填规则、排序和启用状态；字段支持新增、编辑、删除及列表启停。
- 字段类型固定为文本输入、数字输入、标签单选、单项选择、标签多选、多项选择和内容模板，不提供图片类字段类型。
- 字段 ID 全局唯一且创建后不可修改；字段来源支持多选。排序使用非负整数，数字越小越靠前。
- 资料识别映射仅配置各类资料可带入的字段；识别结果统一在资料确认页核对修改，不设置额外的修改权限开关。
- 删除字段时同步清理问题答案关联和资料识别映射；删除问题或字段均需二次确认。
- “发布记录”用于区分草稿和已发布版本。
- 正式版本按 V1.0、V2.0、V3.0 依次递增；记录版本号、状态、时间、发布人、变更摘要和完整配置快照，当前草稿不占正式版本号。

### 教师管理

#### 目标与数据来源

- 目标用户为审核、教务和运营人员，核心任务是查询、查看、审核、编辑和运营教师资料。
- 列表同时包含预置模拟数据与“问答入驻”最新提交的申请。
- 新入驻申请生成唯一 ID，手机号转为脱敏格式，初始状态为“待审核”与“未上架”。

#### 查询条件

| 条件 | 匹配规则 |
| --- | --- |
| 教师姓名 | 姓名关键词模糊匹配 |
| 教师手机号 | 按列表脱敏号码文本匹配 |
| 教师类型 | 按教师当前运营分类精确匹配；选项同步“教师内容管理”中已启用的教师类型 |
| 上架状态 | 已上架/未上架精确匹配，与列表状态开关保持一致 |
| 科目 | 匹配教师主讲科目集合中的任一科目 |
| 审核状态 | 待审核/审核通过/已驳回精确匹配 |
| 注册时间 | 页面已保留日期范围控件，当前原型未连接服务端日期查询 |

“重置”清空查询表单；“搜索”回到第 1 页并显示匹配结果。

#### 列表字段与状态

| 字段 | 展示规则 |
| --- | --- |
| 教师信息 | 头像、姓名、身份标签和教师 ID；姓名可进入只读详情 |
| 手机号 | 按 3-4-4 格式脱敏展示 |
| 教师类型 | 骨干教员、专业教员等运营分类 |
| 主讲科目 | 最多直接展示 3 个标签，超出部分用 +N 表示 |
| 注册时间 | 教师首次进入列表的日期时间 |
| 上架状态 | 开关表示用户端可见状态，原型内修改后立即反映在当前列表 |
| 审核状态 | 待审核为警告标签，审核通过为成功标签，已驳回为危险标签，均同时显示文字 |

#### 详情与编辑

1. 点击教师姓名打开只读详情，所有资料默认不可修改。
2. 点击详情顶部“编辑”后转为可编辑状态；列表行内“编辑”直接打开同一编辑页。
3. 详情左侧摘要展示形象照、姓名、教师类型、身份标签、ID、上架/审核状态、手机号、注册时间、科目和年级。
4. 右侧按基本资料、教学能力、学历与资格认证、教学侧重、教师介绍与形象照分组。
5. 手机号在编辑状态仍不可修改。教龄在查看时只读，编辑时使用与入驻一致的数字输入，支持 0–99 的整数。仅选“小学”时，授课科目限制为语文、数学和英语。
6. 教学侧重以图标、标题和副标题完整展示；个人简介最多 300 字。
7. 重新上传原图后演示 AI 形象照生成状态，生成期间允许保存其他教师资料；教师记录处于“AI 形象照生成中”时，审核入口不可进入审核流程，点击“审核”提示“AI 形象照生成中，请等待生成完成后再审核”。
8. 保存成功后更新当前列表；取消时放弃本次修改、恢复为编辑前的数据并直接关闭弹窗，不返回只读查看页面。
9. “身份证”和“学历证明”均为非必填图片字段，位于“学历与资格认证”分组。身份证与入驻端一致，拆分为“人像面”和“国徽面”两个独立单图上传位，每面最多 1 张，支持预览、重新上传和删除；学历证明支持一次选择多张或分次继续追加，并支持逐张预览和删除。两类图片均支持 JPG、PNG、WebP，单张不超过 10MB，未上传时显示“暂无图片”。
10. 图片修改属于当前教师编辑草稿，点击保存后与其他资料一并生效；点击取消不保留本次新增、替换或删除结果。身份证人像面、身份证国徽面与“身份证号”是三个独立字段。
11. 教师管理不再展示或维护“资质证明”字段；原有该字段展示区从查看和编辑界面删除。

#### 审核规则

- 仅待审核教师在只读详情顶部显示“审核”入口。
- AI 形象照生成中时，不允许审核通过；点击“审核”不打开审核弹窗，仅提示等待 AI 形象照生成完成。
- 审核结论可选“审核通过”或“驳回申请”。
- 驳回时审核意见必填，最多 200 字；通过时意见可选填。
- 提交时显示加载状态，成功后更新列表状态、关闭弹窗并给出结果反馈。

#### 审核状态机

| 当前状态 | 触发动作/条件 | 下一状态 | 结果 |
| --- | --- | --- | --- |
| 新申请 | 教师提交入驻申请 | 待审核 | 进入教师管理待审核列表 |
| 待审核 | AI 形象照仍在生成，点击审核 | 待审核 | 阻断审核并提示等待生成完成 |
| 待审核 | AI 形象照已生成，审核通过 | 审核通过 | 审核流程结束，可继续进行上架操作 |
| 待审核 | 驳回申请并填写审核意见 | 已驳回 | 教师收到驳回原因并补充资料 |
| 已驳回 | 教师补充资料并重新提交 | 待审核 | 生成新的待审核申请，保留历史审核记录 |

审核状态与上架状态相互独立；上架、下架操作不改变审核状态。每次状态变更需记录操作者、操作时间、审核意见和变更前后状态。

#### 操作完成度与边界

- 上下架、详情/编辑和审核已形成本地交互闭环。
- “新增教师”、“虚拟评价”、“关联课程”和“排序”当前仅保留入口。
- 表格勾选与分页用于展示标准列表结构，未连接真实批量操作与分页接口。

### 教师内容管理

#### 定位与使用范围

- 该页是全局内容管理，不归属于单一教师入驻流程。
- “个人简介模板”用于问答入驻的默认值和模板选择。
- “教学侧重”在问答入驻中以标签展示，在教师详情/编辑中以图标、标题和副标题完整展示。
- “教师标签”用于管理端标记教师身份、能力或运营特征，不进入问答入驻。
- “教师类型”用于维护教师的运营分类，并同步给教师详情/编辑中的教师类型选择器。
- “教学成果”用于维护用户端教师主页的案例内容，仅在本页配置，不进入问答入驻、资料确认、教师入驻管理或教师管理。
- 五类内容按“教师类型 → 教师标签 → 个人简介 → 教学侧重 → 教学成果”的标签页顺序切换，避免单页过长；首次进入默认展示教师类型。

#### 个人简介模板

| 字段 | 规则 |
| --- | --- |
| 模板名称 | 必填，最多 20 个字符，不可与其他模板重名 |
| 模板内容 | 必填，最多 300 个字符，非编辑状态单行省略展示 |
| 最近更新 | 保存时更新为当前日期时间 |
| 状态 | 启用后可进入问答入驻候选集；停用后保留数据但不用于新会话 |

1. 点击“新增简介模板”在列表追加空白编辑行；编辑已有模板时直接在原位切换为输入控件，不打开弹窗。
2. 同一时间只允许编辑 1 条；当前行未保存或取消前，其他新增、编辑、删除和状态操作不可用。
3. 保存时显示提交中状态，成功后更新时间、退出编辑并给出反馈；取消时放弃本次草稿。
4. 至少保留 1 条已启用模板；停用或删除最后 1 条已启用模板时阻止操作。
5. 删除前显示影响范围确认，删除后不覆盖教师已保存的个人简介。

#### 教学侧重

| 字段 | 规则 |
| --- | --- |
| 图标 | 必须手动上传，支持 PNG、JPG/JPEG、WebP、SVG，单个文件不超过 200KB |
| 标题 | 必填，最多 20 个字符，全局不可重复 |
| 副标题 | 必填，最多 40 个字符，说明适用问题或教学目标 |

1. 新增和编辑均在列表原位完成，同一时间只允许编辑 1 条。
2. 选择非图片或超过 200KB 时阻止带入；文件读取失败时保留当前编辑内容，可重新上传。
3. 修改教学侧重标题后，当前教师编辑中已选的同名标签同步更名。
4. 删除前需二次确认；至少保留 1 个教学侧重。
5. 删除成功后从问答入驻候选集和当前教师编辑的已选项中移除。

#### 教学成果

| 字段 | 规则 |
| --- | --- |
| 图标 | 必填，手动上传 PNG、JPG/JPEG、WebP 或 SVG，单个文件不超过 200KB |
| 主标题 | 必填，最多 50 个字符，用于描述名次、等级、能力档位或效率变化 |
| 副标题 | 必填，最多 30 个字符，用于描述提升类型和学生称呼 |
| 强化副标题 | 必填，最多 20 个字符，用蓝色强调展示结果，例如“提升 33 名” |

1. 默认预制 20 条通用成果案例，以名次、等级、能力档位、熟练度和效率变化描述提升，不使用具体分数、年级或学科；旧版预制数据自动更新为当前版本。
2. 新增和编辑均在列表原位完成，同一时间只允许编辑 1 条；当前行未保存或取消前，其他编辑操作不可用。
3. 保存前校验图标、三个标题字段和主标题重名；保存中阻止重复提交，成功后写入全局内容配置。
4. 教学成果不提供展示状态和删除操作，保存后的案例始终进入用户端展示。
5. 教学成果只属于教师内容管理，不恢复到入驻表单、资料确认、入驻配置或教师管理详情/编辑。

#### 教师标签

##### 列表

| 项目 | 规则 |
| --- | --- |
| 列表字段 | 序号、标签名称、状态、排序、关联教师数、更新时间、操作 |
| 默认排序 | 排序值从高到低；排序值相同时按更新时间从新到旧 |
| 页头操作 | 不设置搜索筛选区；左侧显示模块说明，右侧显示数据总数和小号“新增教师标签”按钮 |
| 分页 | 支持每页 5、10、20 条；切换每页条数后回到第 1 页 |

无数据时显示教师标签专属空状态，不与加载失败或无权限状态混淆。

##### 新增与编辑

| 字段 | 规则 |
| --- | --- |
| 标签名称 | 必填，2–6 个字符，全局不可重复 |
| 标签状态 | 必填，可选启用或停用；新增默认启用 |
| 排序 | 必填，0–999 的整数，数值越大越靠前；新增默认 100 |
| 关联教师数 | 系统字段，按当前仍关联该标签的教师去重计数；仅在列表正常态展示，新增和编辑时不展示、不填写 |
| 更新时间 | 新增或保存编辑时自动更新为当前日期时间 |

1. 点击“新增教师标签”在当前列表追加空白编辑行；点击已有行“编辑”后在原位切换为输入控件，不打开弹窗。
2. 同一时间只允许编辑 1 条；当前行未保存或取消前，分页、其他新增、编辑、删除和状态操作不可用。
3. 保存前执行必填、长度、范围和重名校验；提交期间显示保存中并禁用重复操作，取消时放弃本次草稿。
4. 标签更名后，已关联教师资料中的同名标签同步更新。
5. 历史标签数据不批量修改；超出 6 个字符的历史名称继续按原值展示，再次编辑该标签时必须修正为不超过 6 个字符，否则不可保存。
6. 教师标签关联发生新增、移除或替换后，列表中的关联教师数同步刷新。

##### 状态与删除

1. 列表状态开关立即生效；停用后不再出现在教师编辑的可选列表中，但已关联教师仍保留该标签。
2. 删除前必须二次确认，确认文案仅询问是否删除，不重复展示关联教师数。
3. 删除成功后从标签列表、教师编辑候选项和已关联教师资料中移除。

#### 教师类型

##### 定位与列表

教师类型是教师资料的全局运营分类，仅供管理端教师详情与编辑使用，不属于教师入驻问答内容。

| 项目 | 规则 |
| --- | --- |
| 列表字段 | 序号、教师类型、排序、排序权重、关联教师数、状态、操作 |
| 默认排序 | 排序值从高到低；排序值相同时按教师类型名称排列 |
| 页头操作 | 不设置搜索筛选区；左侧显示模块说明，右侧显示数据总数和小号“新增教师类型”按钮 |
| 分页 | 支持每页 5、10、20 条；切换每页条数后回到第 1 页 |

1. 无数据时显示教师类型专属空状态。
2. 本页不展示类型说明、来源、更新时间，也不包含首页入口概览、首页展示状态或任何首页 Icon 字段。

##### 新增与编辑

| 字段 | 规则 |
| --- | --- |
| 教师类型 | 必填，2–20 个字符；作为教师详情/编辑中的可选教师类型名称 |
| 排序 | 必填，0–999 的整数，数值越大越靠前；新增默认 100 |
| 排序权重 | 必填，独立数字字段，可输入 0–999 的整数；不替代排序字段，新增默认 100 |
| 关联教师数 | 系统字段，按当前选择该教师类型的教师去重计数；仅在列表正常态展示，新增和编辑时不展示、不填写 |
| 状态 | 必填，可选启用或停用；新增默认启用 |

1. 点击“新增教师类型”在当前列表追加空白编辑行；点击已有行“编辑”后在原位切换为输入控件，不打开弹窗。
2. 同一时间只允许编辑 1 条；当前行未保存或取消前，分页、其他新增、编辑、删除和状态操作不可用。
3. 同一教师类型不可重复；保存前执行必填、长度、范围和重名校验。
4. 提交期间按钮显示保存中并阻止重复提交；成功后退出编辑并更新列表与本地配置，取消时放弃本次草稿。
5. 教师类型更名后，已关联教师资料中的原类型同步更名。
6. 教师类型关联发生新增或变更后，列表中的关联教师数同步刷新。

##### 状态、删除与教师资料同步

1. 状态开关立即生效；停用后不再出现在教师编辑的可选项中，但已保存教师仍保留原类型。
2. 删除前必须二次确认；存在关联教师时提示具体数量及“保留原值但无法再次选择”的影响。
3. 删除只移除类型配置，不清空已保存教师资料；再次编辑时需改选当前已启用类型。
4. 教师详情保持只读；点击“编辑”后，教师类型下拉仅展示已启用数据，并按排序值从高到低排列。
5. 排序权重独立保存，供教师类型相关运营规则使用，不改变本列表和教师类型下拉的展示顺序。

#### 默认值与同步规则

- 问答入驻仅从已启用的个人简介模板中随机带入 1 条。
- 教学侧重随机预选 3 个；候选项不足 3 个时按实际数量带入。
- 老师可在对话或资料确认页修改默认内容。
- 保存后新配置立即写入 `localStorage`，后续进入问答入驻或教师编辑时读取新值，但不覆盖已提交或已保存的教师资料。
- 教学成果与其他内容配置共用本地存储，但只由教师内容管理维护；旧版预制案例会自动更新为当前 20 条通用案例，用户自行新增的数据继续保留。
- 入驻申请以 `experience` 保存具体教龄年数；管理端兼容读取旧版 `experienceRange` 区间数据，并迁移为可编辑的数字值。

#### 原型边界

- 当前使用浏览器本地存储和 Data URL 图标，未接入服务端、对象存储或 CDN。
- 教师标签和教师类型不设置搜索筛选区，已实现本地分页和启停；五个页签统一使用轻量内容清单页头。
- 正式产品需补充权限控制、服务端唯一性校验、引用关系校验、配置版本和操作日志。

## 数据与原型边界

- 原型使用 `localStorage` 演示入驻申请和内容配置的跨页同步。
- 未接入真实 OCR、AI 形象照生成、文件存储、审核、课程、权限、版本和日志服务。
- 刷新、重置浏览器存储或更换浏览器后，模拟数据的表现可能与真实服务不同。
- 当前原型用于验证信息架构、业务规则和交互闭环，不代表最终接口或权限方案。
